# Bucket List Tracker

Live Demo:
https://main.dafd5vprmdxqc.amplifyapp.com

A simple bucket list web app built using React and AWS Amplify.

Features:
- User authentication (Amplify Auth)
- Add, edit, delete bucket list items
- Mark items as completed
- Progress bar to track completion
- Deployed using AWS Amplify Hosting

Tech Stack:
- React
- AWS Amplify
- GraphQL
- Amazon Cognito

To run locally:
npm install
npm start
